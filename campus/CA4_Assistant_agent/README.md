# CA4_Assistant_agent — 캠퍼스 생활 Q&A + 에이전트 대화

담당: AI·데이터 2 · 정의서: [CA4](../docs/캠퍼스에이전트_기능정의서_CA1_CA4.md#ca4--캠퍼스-생활-qa--에이전트-대화)

캠퍼스 생활 질문에는 **공식 자료를 근거로** 답하고, 추천·메뉴 같은 요청은 알맞은 기능을 **대신 불러 주는** 대화입니다. 캠퍼스 앱의 허브라서 CA1·CA2·CA3 가 붙을 때마다 도구가 하나씩 늘어납니다.

## 모듈 계획

| 모듈 | 하는 일 | 정의서 |
|---|---|---|
| `kb` | 문서 · FAQ 등록, 조각내기(300~800자), 메타(캠퍼스 · 카테고리 · 검증일 · 출처 · 부서) | 4-마 · 6절 · 8절 |
| `search` | 하이브리드 검색(키워드 BM25 + 임베딩) → 역순위 합(RRF) 상위 8개, 캠퍼스 필터 | 4-나 · 6절 |
| `answer` | 근거 조각만으로 답하기 · 출처 카드 · 모르면 담당 부서 안내 · 오래된 문서 경고 | 4-나 |
| `agent` | Function Calling 도구 고르기 · 도구 호출 상한 · 미리보기 쓰기(알림 예약) · 범위 밖(학사) 안내 | 4-다 · 4-라 · 5절 |
| `eval` | Q&A 100 · 거절 40 · 도구 선택 50 평가셋과 채점 스크립트 | 13절 |
| `api` | `/v1/agent/chat`(SSE) · `/v1/kb/search` · `/v1/agent/feedback` · 관리자 API | 9절 |

## 지키는 선

- **대화는 계산하지 않는다** — 시간 · 순위 · 메뉴는 도구 결과만 말한다(WE-Meet 요구사항정의서 F9 와 같은 원칙).
- 학사 질문(휴학 · 수강 · 졸업 · 성적 · 장학)에는 답하지 않고 유니버스 PC 앱으로 안내한다.
- robots 규칙이 막은 학교 사이트는 자동 수집하지 않는다 — 문서는 사람이 모아 출처 URL · 검증일과 함께 등록한다.
- 서버는 대화 원문을 저장하지 않는다(평가 로그는 옵트인 · 익명 · 30일).

## 처음 할 일

2. 지식 원천 정리 — 바로 쓸 수 있는 것 / 기관 허락이 필요한 것
