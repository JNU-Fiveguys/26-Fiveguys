# campus/mobile — 캠퍼스 앱 PWA (CA0)

담당: 프론트엔드 · 정의서: [CA0-5 앱 화면 구성](../docs/캠퍼스에이전트_기능정의서_CA1_CA2.md#5-앱-화면-구성-pwa) · [CA1 화면](../docs/캠퍼스에이전트_기능정의서_CA1_CA2.md#9-화면-요구사항-pwa) · [CA2 화면](../docs/캠퍼스에이전트_기능정의서_CA1_CA2.md#10-화면-요구사항-pwa)

폰에서 쓰는 캠퍼스 앱입니다. 설치 없이 브라우저에서 열고 **홈 화면에 추가**해 앱처럼 씁니다(아이폰은 홈 화면에 추가해야 푸시를 받습니다).

## 탭

| 탭 | 경로 | 내용 |
|---|---|---|
| 홈 | `/` | 오늘 카드: 다음 식사 공강 · 날씨 · 추천 1곳 · 빠른 질문 |
| 식사 | `/meal` | CA1 추천 목록 · 상세(`/meal?place=`) · 학식 |
| 에이전트 | `/agent` | CA2 대화 · 출처 카드 · 미리보기 카드 |
| 설정 | `/settings` | 취향 · 알림 · PC 연결(QR 스캔) · 캠퍼스 · 내 데이터 지우기 |
| 관리자 | `/admin` | 팀원 전용: 식당 · 학식 · 지식 문서 · 신고 |

## 지키는 선

- 위치는 소수 셋째 자리로 반올림해서만 서버에 보낸다. 취향 프로필 · 대화 기록은 폰(IndexedDB 등)에만 저장한다.
- 앱에는 API 키를 넣지 않는다 — 외부 API 는 모두 캠퍼스 서버를 거친다.
- 정적 export 라 동적 라우트(`[id]`) 대신 쿼리 파라미터를 쓴다.
- 장소 카드(CA1-S03)는 식사 탭과 에이전트 대화에서 **같은 컴포넌트**를 쓴다.
