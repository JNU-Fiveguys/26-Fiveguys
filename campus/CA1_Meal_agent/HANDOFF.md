- [`scripts/import_places.py`](scripts/import_places.py): 기본 입력은 **selected_candidates.csv**.

- 최초 기본 정보 연결 당시 실제 `places` **100곳**, `attrs` **0곳**이었다. 이후 위의 공개 자료 조사로 부분 attrs와 research를 추가했다.

### 핵심 계산
```
필요 시간 = 도보(출발→식당) + 대기 + 식사 + 도보(식당→다음 건물) + 여유 5분
도보(분)  = ⌈ OSM 보행 경로 거리 ÷ 70 ⌉; 경로 없음 시 직선거리 × 1.3으로 명시적 추정 대체
판정      = 필요 ≤ 공강 → ok · ≤ 공강+5 → tight · 그 밖 → out
leaveBy   = 다음 블록 시작 − 돌아가는 도보 − 여유
예시(테스트로 고정): 공강 100분 · 도보 4/6 · 일반 식당 평시 → 필요 48분 · ok · 여유 52분

점수 = Σ wᵢ·fᵢ  (여유 0.20 · 예산 0.20 · 취향 0.25 · 거리 0.15 · 혼잡 0.03 — 합으로 정규화, 비 오면 거리 ×2)
     + 새 곳 +0.05 · 최근 추천 −0.05 · 시험기간 빠른 식사 +0.05
거리 요소는 왕복 도보 합(walk_total) 기준 (팀원이 변경)
빼기: 정보 없음 · 다시 안 보기 · 종류/특징 필터 · 직접 정한 예산 초과(가장 싼 대표 메뉴 기준)
      · 최대 도보 · 시간 초과 · 영업 아님 → excluded 개수로 돌려줌
이유 칩: 다른 후보 평균보다 기여가 큰 요소 2개
```

### 쓰는 법
```python
from meal.places import load_places
from meal.ranking import rank, MealContext, Filters, TasteSummary
from meal.settings import to_min

ctx = MealContext(weekday=2, start=to_min("11:50"), end=to_min("13:30"),
                  origin=(35.1765, 126.9095), dest=(35.1765, 126.9095), rain=False)
r = rank(load_places(include_samples=True), ctx,
         Filters(budget=7000, budget_explicit=True, include=("일식",)),
         TasteSummary(likes={"일식": 1.0}))
r.to_dict()  # candidates · more · tight · cafeteria · excluded
```
