# CA1_Meal_agent — 공강 맞춤 식사 추천

담당: AI·데이터 1 · 정의서: [CA1](../docs/캠퍼스에이전트_기능정의서_CA1_CA2.md#ca1--공강-맞춤-식사-추천)

이번 공강에 **다녀올 수 있는** 식당·학식을 공강 길이 · 다음 강의실 · 예산 · 날씨 · 취향으로 골라 3곳 추천합니다.

## 모듈 계획

| 모듈 | 하는 일 | 정의서 |
|---|---|---|
| `places` | 상가(상권)정보에서 음식 업종 추출 → `Place`, 팀 조사 속성 `PlaceAttr`, 학식 메뉴 | 4-나 · 7절 |
| `timing` | 식사 공강 계산 · 필요 시간 · 적합/빠듯/제외 판정 | 4-가 · 4-다 · 5절 |
| `ranking` | 규칙 점수 · 반드시 빼는 조건 · 다양성 · 이유 칩 | 4-라 · 5절 |
| `query` | 문장 → `MealQuery`(LLM + 스키마 검증), 실패 시 규칙 파서, 되묻기 | 4-마 · 6절 |
| `taste` | 취향 갱신 규칙(1차 지수이동평균) — 앱이 같은 규칙으로 폰에서 갱신 | 4-바 · 5절 |
| `api` | `/v1/meal/recommend` · `parse` · `explain` · `places` · `cafeteria` · `feedback` · `report` | 8절 |

## 지키는 선

- `/v1/meal/recommend` 가 **유일한 계산기**다 — 식사 화면과 CA2 대화(`recommend_meal`)가 같은 함수를 부른다.
- 카카오 로컬 API 응답은 저장하지 않는다. 지도 링크는 카카오맵 검색 주소로 연다.
- 속성(가격대 · 영업시간 등)이 없는 곳은 추천하지 않는다.

## 처음 할 일

1. `timing` — 정의서 5절 식 + 단위 테스트(예시: 공강 100분 → 필요 48분 · 적합 · 여유 52분)
2. 식당 현장 조사 양식(가격대 · 혼밥 · 좌석 · 영업시간 · 대표 메뉴와 가격 · 검증일)
3. 요청 문장 평가셋 50개 시작(정답 `MealQuery` 포함)
