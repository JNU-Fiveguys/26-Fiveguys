# campus/server — 캠퍼스 서버 (CA0)

담당: 데이터·인프라 · 정의서: [CA0-4 공통 데이터·서버](../docs/캠퍼스에이전트_기능정의서_CA1_CA4.md#4-공통-데이터서버)

캠퍼스 앱과 기능 폴더(CA1·CA4 …)가 함께 쓰는 서버입니다. **공용 데이터와 API 키만** 보관하고, 개인 데이터는 받아도 저장하지 않습니다.

## 맡는 것

| 항목 | 내용 |
|---|---|
| 기기 등록 | `POST /v1/devices` → 익명 `deviceId` + 토큰(서버에는 해시만) |
| PC–폰 연결 | `/v1/pair/start` · `/v1/pair/claim` · `DELETE /v1/pair` — QR 일회용 코드 5분 |
| 오늘 맥락 | `PUT·GET /v1/context` — [스키마](../shared/schema/daily-context.schema.json) 검증, **48시간 뒤 삭제** |
| 건물 마스터 | `GET /v1/buildings` — 원천은 OpenStreetMap(ODbL, 출처 표기) 또는 현장 측정 |
| 날씨 | 기상청 단기예보 조회서비스를 1시간마다 받아 `GET /v1/weather` |
| 푸시 | Web Push(VAPID) 구독·발송, 알림 예약(`/v1/reminders`, 보낸 뒤 삭제) |
| LLM 중계 | 키는 여기에만. 기기당 하루 상한 ⏳60회 |
| 기능 라우터 | CA1·CA4 폴더의 API 를 `/v1/meal/…` · `/v1/agent/…` 로 묶어 띄운다 |

## 지키는 선

- 요청 로그에는 경로 · 응답 코드 · 소요 시간만 남긴다(맥락 · 위치 · 취향 · 대화 원문 금지).
- 학교 로그인 정보 · 이름 · 학번 · 성적을 받는 API 를 만들지 않는다.
- 카카오 로컬 API 를 중계하더라도 응답을 저장하지 않는다.
